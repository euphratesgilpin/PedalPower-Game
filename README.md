# Welcome to PedalPower!

PedalPower is a game I created for a university module - Software Engineering and Systems.
The task was to develop a sustainable solution for the Engineers without Borders Engineering Design Challenge.

# About 

This year, EWB presented us with a location based in Johannesburg, South Africa. 
Throughout the year, my team developed a solution to benefit the local community, encourage healthier lifestyles and give back to them after all the work is done. 

Pedal Power is designed to encourage local residents to cycle to work, school and in their daily lives, increasing safety on roads by decreasing the amount of traffic, and by implementing new cycle lanes that cars are unable to access. The primary focus of this project is to encourage and unite the community in safer travel methods, but it also has some extra perks! 

On the surface, the scheme may appear similar to local ones we know well, however, Pedal Power implements batteries on bikes for the opposite purpose than standard- batteries are charged by the cyclists as they travel. They are plugged into their stations, and the energy gained throughout their journey will charge a large battery embedded in the docking station structure. These specialised stations allow us to essentially create back-up generators in an area that is known to suffer from power outages, meaning important utilities can continue to have power in the event an outage should ever occur.

# The Game

Run the game from the 'gameboard.java' file - it will open and run in a JavaSwing window. Have fun!
